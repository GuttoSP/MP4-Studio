# Editor MP4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar um editor local dedicado, persistente e agradável para MP4, com React, SQLite 3 e FFmpeg real.

**Architecture:** Uma SPA React/Vite consome uma API Express local. SQLite persiste projetos, assets, revisões e renders, enquanto arquivos grandes permanecem sob uma raiz controlada; um runner FFmpeg separado monta argumentos validados, executa sem shell e publica progresso persistente.

**Tech Stack:** Node 24, TypeScript 5, React 19, Vite 7, Express 5, `node:sqlite`, Multer, Lucide React, Vitest, Testing Library, Supertest, Playwright, FFmpeg/ffprobe de `D:\AI`.

## Global Constraints

- O projeto físico deve permanecer em `D:\projetos\editor_mp4`.
- Não modificar nem iniciar o ComfyUI Central e não tocar em sua fila ou porta.
- Escutar apenas em `127.0.0.1` e não fazer chamadas externas em runtime.
- Usar SQLite 3 em `data/editor-mp4.sqlite3` com WAL e foreign keys.
- Preferir `D:\AI\ffmpeg-shared\ffmpeg-master-latest-win64-gpl-shared\bin` para FFmpeg e ffprobe.
- Nunca modificar arquivos originais; aceitar apenas IDs opacos no navegador e validar toda resolução sob `data`.
- Usar `spawn` com argumentos e `shell: false` para FFmpeg/ffprobe.
- Toda alteração funcional começa com um teste que falha e termina com teste focado passando.
